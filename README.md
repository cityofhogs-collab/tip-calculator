# Tip Calculator

A simple command-line tool to calculate tips and split bills.

## Usage

```bash
python tip_calculator.py
```

You'll be prompted for:
- Bill amount
- Tip percentage
- Number of people

## Example

```
Bill amount: $50
Tip percentage: 20
Number of people: 4

Tip: $10.0
Total: $60.0
Per person: $15.0
```
